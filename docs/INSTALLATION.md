# Installation (retired)

The standalone DCS-UI-Layer OVGME package is retired and must not be used for new installations.

DCS-Common now owns the definitive UI Layer. Supported aircraft/component packages project and install only the UI Layer controls selected by that module. Install the appropriate module package instead of this repository's former all-inclusive package.

Do not enable an historical DCS-UI-Layer package alongside a current module package. Both target the shared Saved Games `Config/Input/UiLayer` location and can overwrite one another.

Existing tags and releases are retained only for rollback and historical reference. See the [DCS-Common definitive UI Layer documentation](https://github.com/ScottyMac52/DCS-Common/blob/main/docs/definitive-ui-layer.md) for the supported workflow.
